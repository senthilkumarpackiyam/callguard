# CallGuard

A question-answering assistant for security vulnerabilities in contact-center and UC products (Cisco, Avaya, Mitel, Asterisk/FreePBX and others). It answers from live NVD, CVE.org, CISA KEV and FIRST EPSS data, cites every claim, and says so when it has no matching records.

Work in progress for the GEN ACADEMY RAG course. See [ROADMAP.md](ROADMAP.md) for the plan and [NOTES.md](NOTES.md) for the build log.
